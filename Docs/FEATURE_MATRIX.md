# Feature matrix

Generated by `AnomalyPulse/features/document_columns.py`; do not edit by hand. Re-run it when a feature changes.

- **One row per one-minute window** of one experiment, named by the window's start time. The join key to labels is `(experiment_id, window start)`; neither is a column.
- **Every column is Tier-1**: derived from observable telemetry or CloudWatch counts. No Tier-2 name, join key, label or fault parameter is a column. `features/guard.py` fails the build if one appears.
- **Empty means unknown, not zero.** A service with no requests in a window has an empty latency or error rate. Counts and request rates are `0`.
- **Temporal columns use only the current and earlier windows** of the same run.
- A run's first and last windows can be partial. Which windows to drop is decided with M4-4.
